# Doll Clock

> **Learning project** · Interactive browser UI built with vanilla web technologies.

A small frontend project centered around a live clock and a set of interactive visual effects.

## Features

- Live time, date and weekday display
- Controls for changing the clock size
- Interactive color changes
- Hover-driven typography effects
- Image scale and opacity transitions
- Basic DOM event handling

## Tech Stack

`HTML5` · `CSS3` · `JavaScript`

## What I Practised

This project was created to practise direct DOM manipulation, browser events, CSS transitions and small UI interactions without a framework.
